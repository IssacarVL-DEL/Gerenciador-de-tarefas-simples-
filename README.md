# Gerenciador de Tarefas: planner diário com painel

Lista de tarefas com prazo e um painel com o progresso do mês, feita só com HTML, CSS e JavaScript, sem framework.

## O que faz

- Adiciona tarefas com descrição e prazo (data).
- Marca como concluída ou reabre, e exclui tarefas.
- Guarda tudo no navegador (`localStorage`, em JSON), então as tarefas continuam lá depois de fechar a página.
- Mostra um painel com o total de tarefas, as concluídas no mês e um gráfico de rosca (concluídas x pendentes do mês), feito com Chart.js.

## Tecnologias

HTML5, CSS3, JavaScript (ES6), Chart.js 4 e a fonte Poppins (Google Fonts).

## Como rodar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` no navegador.

Não precisa instalar nada.

## Estrutura

- `index.html`: página com o formulário, a lista e o painel.
- `style.css`: layout e estilos.
- `script.js`: regras da lista, armazenamento e gráfico.
- `Gerenciador De Tarefas/`: cópia dos mesmos três arquivos.
